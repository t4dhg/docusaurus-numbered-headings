# Security Policy

## Supported versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

Only the current 2.x release line receives security updates.

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the repository's
[security advisory form](https://github.com/t4dhg/docusaurus-numbered-headings/security/advisories/new).
Do not open a public issue or disclose the vulnerability publicly before the
maintainer has had a reasonable opportunity to investigate and coordinate a
fix.

Include the affected package version, impact, reproduction steps or a minimal
reproduction, and any suggested remediation. Remove credentials and unrelated
private data from the report.

The maintainer will acknowledge reports when reasonably possible, assess the
reported impact, and share updates as the investigation progresses. Response
and remediation time depend on severity, reproducibility, and upstream
dependencies; no fixed response or resolution time is promised.
